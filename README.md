# 💼 Portfolio Website

My personal portfolio website with a modern dark theme and purple accents.

## 🛠️ Tech Stack

- HTML5, CSS3, JavaScript, PHP
- Bootstrap 5

## 📁 Structure

```
├── index.php         # Homepage
├── css/style.css       # Styles
├── js/script.js        # Scripts
└── pages/
    ├── about.php
    ├── skills.php
    ├── projects.php
    ├── faq.php
    ├── contact.php
    └── thankyou.php
```

## 🚀 Quick Start

```bash
git clone https://github.com/WeXxQ-o/Portfolio.git
cd Portfolio
# Open index.php in browser
```

# 💼 Portfolio Website

My personal portfolio website with a modern dark theme and purple accents.

## 🛠️ Tech Stack

- HTML5, CSS3, JavaScript
- Bootstrap 5

## 📁 Structure

```
├── index.html          # Homepage
├── css/style.css       # Styles
├── js/script.js        # Scripts
└── pages/
    ├── about.html
    ├── skills.html
    ├── projects.html
    ├── faq.html
    ├── contact.html
    └── thankyou.html
```

## 🚀 Quick Start

```bash
git clone https://github.com/WeXxQ-o/Portfolio.git
cd Portfolio
# Open index.html in browser
```
